# JAAM Quiz

A roguelike quiz inspired by Slay the Spire. Pick a path through themed nodes, answer questions against a timer, and survive with 3 lives.

## Run it

Open `index.html` in your browser. Nothing to install currently.

## Formatting

We use Prettier. Install the **Prettier Code formatter** extension in VS Code and your files will be formatted for you on save, [Find it here.](https://marketplace.visualstudio.com/items?itemName=esbenp.prettier-vscode)
